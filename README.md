# Coding Practice

코딩테스트를 준비하며 해결한 알고리즘 문제의 풀이를 기록하는 저장소입니다.  
정답을 제출하는 데서 끝내지 않고, 문제에 맞는 자료구조와 알고리즘을 선택하는 연습을 꾸준히 이어가는 것을 목표로 합니다.

## Overview

| 항목 | 내용 |
| --- | --- |
| 문제 출처 | [프로그래머스](https://programmers.co.kr/) |
| 사용 언어 | C++ |
| 파일명 규칙 | `문제명.cpp` (공백은 `_`로 표기) |

## Repository Structure

```text
coding-practice/
├── README.md
└── programmers/
    ├── level-1/
    │   └── 문제명.cpp
    └── level-2/
        └── 문제명.cpp
```

풀이 파일은 플랫폼과 난이도에 따라 분류합니다. 각 파일에는 프로그래머스에서 요구하는 `solution` 함수를 기준으로 풀이가 작성되어 있습니다.

## Study Rules

1. 문제를 충분히 고민한 뒤 풀이를 작성합니다.
2. 변수와 함수의 역할이 드러나는 이름을 사용합니다.
3. 틀린 문제는 원인을 확인하고 다시 풀이합니다.
4. 새 풀이는 `solve: [programmers] 문제명` 형식으로 커밋합니다.
